# 道具の素材

## crochet_hook.svg(かぎ針)
- どうぶつの絵と同じ viewBox(0 0 240 240)・同じ位置で重ねる。6匹とも同じ位置で使える
- かぎ針の作品のとき:
  - 右の手(回転の中心 138,150 のまとまり):棒針(線2本と赤い玉)を消して、代わりに `crochet-right` の中身を入れる。手の絵より前(下)に入れて、手がかぎ針を握っているように見せる
  - 左の手(回転の中心 102,150 のまとまり):棒針(線2本と赤い玉)を消して、手だけにする(編み地を持つ手)
- ひつじは棒針と手のまとまりの作りがほかの5匹とちがうので、同じ見た目になるように入れる(見本:docs/mockups/sheep-legs.png の右)
- 見本:docs/mockups/crochet.png(ひつじ以外の5匹)、docs/mockups/sheep-legs.png
- 絵は描き直さず、このまま使う
