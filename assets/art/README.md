# 新しい絵(画像AIのイラスト)

画像AIで描いた透明PNGを置く場所です。描き方・ファイル名・キャンバスの大きさは `docs/art/art-guide.md` を見てください。

## 置き方
- PNGを、art-guide のファイル名のまま、このフォルダに入れる(例:`sheep_body.png`)
- アプリは部品ごとに「PNGがあればPNG、なければ今のSVGの絵」を使う。少しずつ入れてよい
  - どうぶつは `<どうぶつ>_body.png` がある子だけ新しい絵になる。ほかの部品(目・手・body-mask)がないときは、その部品だけ今のSVG
  - 手は左右2枚そろったときだけ使う(手袋の `_left` / `_right` も同じ)。かぎ針の手がなければ棒針の手
  - body-mask がないときは、体の色を付けない。手も同じで、手のマスク(`<手の画像の名前>_mask.png`)がない手には体の色を付けない
  - 身につける作品のPNGは、新しい絵の子にだけ使う。頭飾りのPNGは、どの子・部屋の鉢植え・選ぶ画面の小さな絵にも使う
- 中身は変えずに使う(アプリが軽い版を作る。下の `npm run art`)

## 位置のずれを直す(art.json)
数字はすべて art-guide と同じ **キャンバスの点(px)** で書きます。書いていない項目は art-guide のとおりの値になります。数字でないもの・大きすぎるものも、art-guide のとおりの値になります。

```json
{
  "animals": {
    "sheep": {
      "decoration": { "x": 480, "y": 200 },
      "hatDecorationY": 140,
      "handLeft": { "x": 408, "y": 600 },
      "handRight": { "x": 552, "y": 600 },
      "knit": { "x": 416, "y": 584, "width": 128, "minHeight": 16, "maxHeight": 176 }
    }
  },
  "decorations": { "tulip": { "x": 136, "y": 247 } },
  "room": { "cushion": { "x": 144, "y": 208 } }
}
```

| 項目 | 中身 | キャンバス | art-guide のとおりの値 |
| --- | --- | --- | --- |
| `animals.<どうぶつ>.decoration` | 頭飾りの位置(頭のてっぺんの真ん中) | 960×960 | 下敷き画像の緑の丸 |
| `animals.<どうぶつ>.hatDecorationY` | 帽子をかぶっているときの頭飾りの高さ(y だけ) | 960×960 | 今の帽子の高さ(ひつじ 140、アザラシ 184) |
| `animals.<どうぶつ>.handLeft` / `handRight` | 左右の手の回転の中心 | 960×960 | (408, 600) / (552, 600) |
| `animals.<どうぶつ>.knit` | 編み地の四角:左上(x, y)・幅・いちばん短いとき/長いときの高さ。上の端は動かず、下に伸びる | 960×960 | x 416・y 584・幅 128・高さ 16〜176 |
| `decorations.<名前>` | 頭飾りが頭に触れる点 | 272×272 | (136, 247) |
| `room.<名前>` | 部屋に飾る作品が床に触れる点 | 288×232 | (144, 208) |

## 軽い版を作る(npm run art)
- `npm run art` で、このフォルダのPNGから、アプリで使う軽い版を `src/art/generated/` に作る(元の絵は変えない。git には入らない)
  - まわりの透明な部分を切り落とし、色の数を256色にしたPNGにする。大きさは縮めない(縮める割合は `scripts/art.mjs` の `SCALE`)
  - 元の重さ → 軽い版の重さを、1枚ずつと合計で表示する
  - art-guide にない名前のファイルは使わない(名前を表示するので、確かめる)
- `npm run dev`・`npm run build`・`npm test` の前にも自動で動く(Cloudflare Pages でも作られる)
- 別のフォルダの絵で確かめるとき:`ART_DIR=<フォルダ> npm run dev`(PowerShell では `$env:ART_DIR="<フォルダ>"; npm run dev`)
