# 身につける作品・部屋に飾る作品の素材

試作で仕上げた絵です。描き直さずに、このまま使ってください。見本の画像は docs/mockups/ の wear.png・wear-two.png・room-items.png。

## 決まっていること
- 絵は部門ごとに1つ。種類名(帽子・耳当てなど)が違っても同じ絵で、色は作品の色になる
- 1匹が同時に身につけられるのは、部門ごとに1つずつ(例:ねこはマフラーと手袋を同時に)
- 「小物やインテリア」は3種類の絵(クッション・ブランケット・あみぐるみ)から選ぶ
  - 作品を作るときに選ぶ。種類名がクッション/ブランケット/あみぐるみならその絵を、それ以外(コースター・ポーチ・自由入力)はクッションを最初から選んでおく。あとから選び直せる
- 部屋に飾れるのは最大3つ(置き場所3か所。位置は wear.json の roomSpots)

- どうぶつの絵と同じ viewBox(0 0 240 240)・同じ位置で重ねる
- 部品のまとまり(重ねる場所)
  - `wear-body`:どうぶつの体の上、編んでいる作品(x=104 y=146 の四角)の下に入れる(SPEC.md の「2. 身につけた作品」)
  - `wear-hand-left` / `wear-hand-right`(手袋だけ):左右の手のまとまりの中、手の絵のあとに入れる。手と一緒に回るようにするため
- 帽子をかぶっているときは、頭飾りの位置(y)を wear.json の decorationAnchorY に変える(xと大きさはそのまま)
- ひつじの帽子の頭飾りは絵の上の端(y=0)より上にはみ出す。切れないようにする

## 部屋に飾る作品(3種類)
- interior_cushion.svg / interior_blanket.svg / interior_amigurumi.svg
- viewBox -36 -52 72 58。(0,0) が床に触れる下の真ん中
- roomSpots の (x, y) に translate して scale をかける

## 色の付け方(大事)
- 色は CSS 変数 `--item`(作品の色)と `--item-shade`(作品の色を約15%暗くした色)
- 編み目の模様は `<pattern>` で、模様の中で CSS 変数を使っている。CSS 変数は「pattern が置かれた場所の親」から引き継がれるので、次の2つを守る
  1. `<defs>`(pattern)は、各まとまり(`wear-body` など)の中に入れたままにする。外に出すと色が付かない
  2. pattern や mask・clipPath の id は、作品ごとに別の名前にする(ファイルでは `wk-head_sheep` のように作品の種類で分けてある。同じ部屋に同じ種類の作品が2つ並ぶときなどは、さらに別の名前にする)
- 手袋は左手のまとまりにだけ `<defs>` がある。右手は左手の pattern を使うので、左右同時に入れる
