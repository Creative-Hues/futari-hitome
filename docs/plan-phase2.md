# フェーズ2「パートナー」計画

## Context
フェーズ1(修正1まで)は iPhone で確認ずみ。今はパートナーがひつじに固定で、`<img>` で絵を置いているだけ(動きなし)。
フェーズ2では、6匹から部門の担当を選べるようにし、パートナーが「一緒に編んでいる」と感じられる動き(編む・ほどく・編み地が伸びる・呼吸・まばたき・ふれあい)と、時間帯で変わる空を入れる。

フェーズ2の範囲(SPEC.md より)
- 6匹の素材を使った部品の重ね合わせ、部門ごとの担当から選ぶ仕組み、動物ごとの個体データ
- 編む動き・ほどく動き、進み具合に合わせた編み地、目標なしの進行度タップ、ふれあい
- 花の揺れ・雲の上下・どうぶつの呼吸とまばたき、時間帯で変わる空

入れないもの:頭飾りの付け替え・体や目の色の変更・着せ替え・なかま画面・パートナーの画面(フェーズ4)、作品タブ・同じ子の切り替え・完成の演出(フェーズ3)、部屋の模様替え(フェーズ4)。

## 素材の確認でわかったこと
- 6匹とも viewBox 0 0 240 240、編み地は `<rect x=104 y=146 width=32 ... fill="url(#knit)">` で共通
- ねこ・オコジョ・ウーパールーパー・アザラシ・ラッコの5匹は、左右の「手+編み針」がそれぞれ `<g transform="rotate(0 102 150)">` / `rotate(0 138 150)` にまとまっている
- **ひつじだけは**、編み針2本 → 玉2つ → ひづめ2つ の順に並んでいて、左右に分かれていない
- 目は黒い丸(`#1a1620`)、ひつじだけ白い点(`#fdfbff`)
- どのSVGも `wool` `knit` `stitch` などの同じ名前(id)を使っている。ホームでは作品カードの小さな絵と部屋の子が同時に出るので、同じ画面に何匹も並ぶと名前がぶつかる

## 絵の扱い方(素材は変えない)
動かすためには、`<img>` ではなく SVG を画面の中に直接入れる必要がある。そこで:
- assets/ のファイルは**一切書き換えない**。アプリが読み込んだあと、メモリの中で次の「印付け」だけをする(`src/lib/partnerSvg.ts`)
  1. id の名前の前に1匹ずつ違う文字を付ける(同じ画面に何匹いてもぶつからないように)
  2. 編み地・左右の手・目・頭飾りに、CSSで動かすための目印(class)を付ける。形・色・位置は変えない
  3. 編み地の高さを進み具合に合わせて変える(README のとおり 4〜44)
  4. 編み地の色(`#knit` の塗りと線、外の線)を作品の色に差し替える(README のとおり)。線の色は作品の色を自動で少し濃くして作る
  5. **ひつじだけ**、編み針・玉・ひづめを左右の2つのまとまりに分ける(ほかの5匹、および docs/mockups/Knit.mock.html のひつじと同じ並び)。左右を別々に動かすために必要。重なりの順が「左の手→右の手」に変わるが、試作の Knit.mock.html と同じ見た目になる
- 頭飾りは anchors.json の位置・大きさのまま、同じ SVG の中に重ねる(重ねる順は SPEC の 1→5 のとおり。「身につけた作品」はフェーズ4)
- 原っぱ(meadow.svg)とホームの部屋(room_example_0.svg)も同じように画面に直接入れ、雲・花・空の色に目印を付ける(`src/lib/sceneSvg.ts`)
- テスト:6匹すべてで「編み地1つ・左右の手・目2つ」が見つかること、id がぶつからないこと、編み地の高さと色が変わることを確かめる(SVGを読むために、テスト用に `happy-dom` を入れる)

## 作るもの

### 1. パートナーを選ぶ(新しく編む画面)
- 部門を選ぶと、その部門の担当2匹がカードで並ぶ(絵+名前)。タップで選ぶ。部門を変えたら選び直し
- まだ一緒に編んだことのない子には小さく「はじめまして」と出す
- 選ぶまで「はじめる」は押せない
- 作品を作った時点で、その子は「出会った」ことになる

### 2. 動物ごとの個体データ
- IndexedDB に `partners`(6件)を追加。項目:動物の種類・出会ったか・出会った日・頭飾り(最初は anchors.json の最初の頭飾り)・体の色・目の色・身につけている作品のID・名前
  - 体の色・目の色・身につけている作品は、入れ物だけ用意して空のまま(使うのはフェーズ4)
- 作品に「目標なしの進行度(%)」を追加
- データのバージョンを 1 → 2 に上げる。直し方:6匹分の `partners` を作り、今ある作品のパートナー(ひつじ)を「出会った」にする。作品には進行度 0 を足す。フェーズ1のデータはそのまま読める

### 3. 画面ごとのパートナー
- **編む画面**:その作品の子が、その子の頭飾りをつけて編む。編み地の色は作品の色
- **ホーム**:部屋にいるのは最後に編んだ子(いちばん最近数えた作品の子。作品がなければひつじ)
- **作品カードの小さな絵**:その作品の子(小さいので動きは付けない)

### 4. 動き
すべて CSS アニメーション。速さ・揺れ幅などは **`src/styles/tokens.css` の「動き」の欄だけ**で変えられるようにする(フェーズ1の「+1」や音声の点滅と同じ場所)。
- **編む動き**:数えるたびに(タップ・+N・音声どれでも)左右の手が編み針ごと小さく交互に動く。すばやく続けて数えても毎回動きが始まり直す
- **編み地が伸びる**:進み具合に合わせて高さがなめらかに変わる
  - 目標あり:達成率で 4〜44(100%を超えたら44のまま)
  - 目標なし:「今このくらい」の進行度で
- **ほどく動き**:「ほどく」をしたとき、手が逆向きに数回動き、編み地が縮む。取り消しで戻したときは高さが変わるだけ
- **呼吸**:体全体(頭飾りも一緒に)が小さく上下
- **まばたき**:ときどき目が閉じる(目の丸を縦につぶすだけ)。編む画面とホームの子
- **ふれあい**:パートナーをタップすると、しぐさを1つ(ぴょんと跳ねる/左右にゆれる/首をかしげる/ゆっくりまばたき)。前と同じしぐさが続かないように選ぶ。編む画面とホームの両方
- **花の揺れ**:頭飾り(頭に触れる点を中心に)、原っぱのチューリップとデイジー、部屋の鉢植えの花
- **雲の上下**:原っぱと部屋の窓の雲がゆっくり上下
- iPhone の「視差効果を減らす」がオンのときは、呼吸・まばたき・揺れ・雲を止める(数えたときの動きは短く残す)
- 設定する値の例:呼吸の速さ・高さ/まばたきの間隔・長さ/花の揺れの角度・速さ/雲の上下の幅・速さ/編む動きの角度・速さ/ほどく動きの回数・速さ/編み地の伸びる速さ/ふれあいの跳ねる高さ・ゆれる角度

### 5. 目標なしの進行度タップ(編む画面)
- 目標なしの作品にも進みのバーを出し、「今このくらい」をタップ(または指でなぞる)すると、そこまでパートナーが編み進める。5%きざみ。横に「だいたい 40%」と出す
- バーの見た目は今と同じ細さで、触れられる高さは44px以上にする
- カウントとは別なので、取り消しの対象にはしない(タップし直せば直せる)
- ホームの作品カードのバーにも同じ進行度を出す

### 6. 時間帯で変わる空
- 端末の時計で 朝(5〜10時)・昼(10〜16時)・夕方(16〜19時)・夜(19〜5時)。1分ごとと、アプリに戻ってきたときに確かめる
- 空のグラデーション3色と雲の色を時間帯ごとに差し替える。昼は素材そのままの色
- 夜は雲を暗くし、星を出す。原っぱと床も少しだけ暗くする(暗さは設定で変えられ、1にすれば暗くしない)
- 時間帯の区切りと色は `src/config/sky.ts` の1か所にまとめる
- 原っぱ(編む画面)と部屋の窓(ホーム)の両方

## フェーズ1の動きを変えないために
- **触らないファイル**:`noZoom.ts`(拡大の防止)、`tapGuard.ts` と `tuning.ts`(すばやいタップ・誤タッチ防止)、`voice.ts` と `voiceParse.ts`(音声)。編む画面のタップ場所・音声ボタンの部分も中身は変えない
- パートナーは原っぱの中にいて、タップ場所の外。パートナーをタップしても数えない。タップ場所の動きの判定には関わらない
- 動きは「数えた結果」を見て始めるだけで、数え方には関わらない。絵は最初に1回だけ作り、数えるたびには作り直さない(すばやいタップでも重くならないように)。動きの部分は指の操作を受け取らない
- 確かめ方:今あるテスト(すばやいタップ・2本指・音声の読み取り)がそのまま通ること。PC で続けて素早くタップして数がずれないこと。iPhone での確認手順にも入れる

## 確認したいこと
1. **ひつじの手の分け方**:上の「絵の扱い方 5」のとおり、ひつじだけ部品の並びをほかの5匹と同じにしてよいか(形は変えない)
2. **夜の星**:素材に星がないため、小さな白い点(丸)を空に数個置く形にしたい。新しく描くことになるので、これでよいか(ほかの形がよければ素材を用意してもらう)
3. **時間帯の区切り**:朝5〜10時・昼10〜16時・夕方16〜19時・夜19〜5時でよいか

## 確認したことへの答え(OKずみ)
1. ひつじの手:左右2つのまとまりに分ける。形は変えない
2. 夜の星:小さな丸を空に数個。色は少し黄色寄りの白(#fffbe8)。ゆっくりまたたく。速さは tokens.css の「動き」の欄で変えられる
3. 時間帯:朝5〜10時・昼10〜16時・夕方16〜19時・夜19〜5時

## 追加:確認用の ?sky=
- アドレスの最後に `?sky=morning` / `?sky=day` / `?sky=evening` / `?sky=night` を付けると、その時間帯の空で表示する(公開版でも使える)
- `#` の前(`/?sky=night#/`)でも後ろ(`#/knit/…?sky=night`)でもよい。`#` の後ろに付けても行き先の判定には含めない
- 付けていないとき・正しくない値のときは、今までどおり今の時刻で決める
- 保存はしない。付けたアドレスで開いた画面だけに効く
- 開発中だけ使えた `?time=` は、これに置き換える
