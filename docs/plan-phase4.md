## 素材の確認でわかったこと
- 身につける絵は10個。どれも viewBox 0 0 240 240 で、まとまり `wear-body`(帽子・マフラー・セーター・くつした)か、`wear-hand-left` / `wear-hand-right`(手袋)に分かれている。部屋の絵3つは `wear-room`
- 色は `--item` / `--item-shade`。ファイルの一番外の `<svg style="--item:…">` は見本の色なので、使うのは中のまとまりだけ
- 模様(pattern)の `<defs>` は各まとまりの中にある。手袋は左手のまとまりにだけあり、右手はそれを使う。セーターは mask と clipPath も使う
- 担当の組み合わせは12通り。身につける10通り+小物やインテリアの2通り(ひつじ・ウーパールーパー)で、全部そろっている
- どうぶつの体の白は `wool` のグラデーション(3色)と編み目の線 `stitch`、目は `.pt-eye`(フェーズ2で目印ずみ)。体の色・目の色はここを差し替えれば変えられる
- 部屋のテンプレート `room_template.svg` は、色を CSS 変数(--wall など)で持っている。ただし一番外の `<svg>` に見本の色が直接書いてあるので、外から変数を渡すにはこの style を外す必要がある
- 鉢植えの花は `translate(244 133)` の中の `translate(0 -15) scale(1.35)` のまとまり。見本の4つの部屋も、ここに頭飾りの花をそのまま入れている

## 2. パートナーの絵に、身につけた作品を重ねる
フェーズ2と同じく、assets/ のファイルは書き換えず、読み込んだあとメモリの中で重ねるだけ(`src/lib/wearSvg.ts`、`partnerSvg.ts` から呼ぶ)。
- 部門 → 絵:頭 `head_`・首 `neck_`・胴体 `body_`・前足 `paws_`・身につけるもの `feet_` + どうぶつ名(例:ねこの前足 → `paws_cat.svg`)。種類名が違っても同じ絵
- **重ね方(README のとおり)**
  - `wear-body`:どうぶつの体の上、編み地(x=104 y=146 の四角)の**すぐ前**に入れる。2つ以上身につけているときは、セーター → くつした → マフラー → 帽子 の順に重ねる(アザラシの帽子+セーターなど、wear-two.png と同じ重なり)
  - 手袋:`wear-hand-left` を左手のまとまり(`.pt-hand-l`)の中、手の絵のあとに、`wear-hand-right` を右手の中に入れる。手と一緒に回る。左右は必ず同時に入れる
- **色の付け方**:作品ごとに、まとまりを `<g style="--item: 作品の色; --item-shade: 約15%暗くした色">` で包む。`<defs>` は**各まとまりの中に置いたまま**動かさない(外に出すと色が付かないため)。手袋は左右とも同じ色の入れ物で包む
- **id**:作品ごとに頭に別の文字を付ける(`wk-head_sheep` → `p3-w-head-wk-head_sheep` のように)。同じ画面にパートナーが何匹いても、同じ種類の作品が並んでもぶつからない。手袋の右手が左手の pattern を指すのは、同じ文字を付けるのでそのまま保たれる
- **頭飾りの位置**:帽子をかぶっているときは、頭飾りの y を wear.json の `decorationAnchorY`(ひつじ35・アザラシ46)にする。x と大きさはそのまま
- **ひつじの帽子**:頭飾りが絵の上の端(y=0)より上にはみ出す。パートナーの絵ははみ出しても見えるようにしてあるが、枠のある場所(なかまのカード・作品カードの小さな絵・パートナーの画面)では、上が切れないよう絵の上に余白をとる
- 体の色・目の色も同じ下ごしらえで CSS 変数にする(`wool` の3色・編み目の線・ねこやオコジョのしっぽの白い線 → `--body-*`、`.pt-eye` → `--eye`)。色を変えても絵は作り直さず、変数を変えるだけ
- 身につけた作品は**パートナーが出るすべての場所**(編む画面・ホームの部屋・お祝い・作品カードの小さな絵・新しく編む・アルバム・なかま・パートナーの画面)で同じように出す
- 絵を作り直すのは、頭飾りや身につけるものが変わったときだけ。数えるたびには作り直さない(すばやいタップでも重くならないように)
- テスト:12通りすべてで、`wear-body` が編み地の前にあること/手袋が左右の手の中にあること/`<defs>` がまとまりの中にあること/2匹並べても id がぶつからないこと/帽子のとき頭飾りの y が変わること

## 4. パートナーの画面(`#/partner/:animal`)
試作の画面はないので、ほかの画面と同じ部品(白いカード・角丸・Zen Maru Gothic・44px以上)で作ります。上から:
1. 戻るボタン+名前
2. **大きな絵**(水色のカードの中。呼吸・まばたき・タップでしぐさ)。下の欄を変えると、すぐこの絵に反映される
3. **頭飾り**:10種類を「花」「葉っぱ」「海」の3つに分けて並べる(頭飾りの絵+名前)。どの子もどれでも選べる
4. **体の色**・**目の色**:色の丸を並べる(→ 確認したいこと 2)。一番左は「もとの色」
5. **身につける**:その子の担当部門ごと(小物やインテリアを除く)に、「なし」+その子がもらった完成作品のカード(作品の色の丸・作品名・完成した日)。押したものを身につける。部門ごとに1つずつなので、ねこはマフラーと手袋を同時に身につけられる
6. **部屋に飾る**(ひつじ・ウーパールーパーだけ):もらった小物やインテリアの作品(その絵を作品の色で表示・作品名)。「飾る / はずす」のボタン。3つ飾っているときに「飾る」を押すと「部屋に飾れるのは3つまでです。部屋の模様替えで、はずす作品を選んでください」と出す
7. **一緒に編んだ作品**:編みかけ(押すと編む画面)と完成(押すとアルバムの記録)
- 変えたものはその場で保存
- **まだ会っていないとき**:薄い絵と「○○の作品(担当の部門)を編むと会えます」だけを出す(着せ替えなどの欄は出さない)

## 5. 部屋に飾る
- **部屋の絵**:ホームの部屋を `room_template.svg` に切り替える(色を変えられるように)。飾った作品は wear.json の `roomSpots` の位置に `translate(x y) scale(大きさ)` で置く(床の右 1.0 / ラグの左手前 0.85 / 窓辺 0.6)
  - 重なり:部屋の家具の上、夜に暗くする幕と星の下(夜は作品も一緒に暗くなる)。パートナーは部屋の絵の上に重なる
  - 色の付け方と id はパートナーと同じ(作品ごとに `--item` の入れ物で包み、`<defs>` は中のまま、id は置き場所ごとに別の文字。同じクッションが2つ並んでもぶつからない)
- **絵の選び方**
  - 新しく編む画面:部門で「小物やインテリア」を選ぶと、種類名の下に「部屋に飾るときの絵」として3つ(クッション・ブランケット・あみぐるみ)を作品の色で並べる。種類名に合わせて最初から選んでおく(クッション/ブランケット/あみぐるみ → その絵、それ以外 → クッション)。種類名を変えたら選び直すが、自分で絵を押したあとは種類名を変えても変えない
  - あとから選び直す:編む画面のメモのシート(編みかけ)と、完成記録の画面(完成)に同じ3つの選択を出す
- 飾る作品の選び方:パートナーの画面(上の 6)と、部屋の模様替え(下の 6)

## 6. 設定と部屋の模様替え
- ホーム右上に**歯車**(試作の位置と見た目、44px)→ `#/settings`
- **設定**(`#/settings`):戻るボタン+「設定」。カードが2つ
  - 「部屋の模様替え」→ `#/settings/room`
  - 「音声で数える言葉」(下の 7)
- **部屋の模様替え**(`#/settings/room`)
  - 上に部屋の絵(画面の上に止めておき、下の欄をスクロールしても見える)。変えるとすぐ反映。パートナーはホームと同じ子
  - **おすすめ**:room_palettes.json の4通り(はじめの部屋・ミント・ラベンダー・そらいろ)。押すと6色と花がまとめて変わる。room-colors.png のように色の丸を並べた小さなカード
  - **色**:壁・床・カーテン・ラグ・毛糸玉1・毛糸玉2 をそれぞれ色の丸から選ぶ(すべて単色。→ 確認したいこと 3)
  - **影や境目の色**は選んだ色を自動で少し濃くする(壁・床の影、毛糸玉の影)。濃くする割合は、素材の見本(はじめの部屋)と同じ色になる値を `src/config/room.ts` の1か所に置く
  - **鉢植えの花**:頭飾りの花7つ(チューリップ・コスモス・アジサイ・サクラ・デイジー・新芽・クローバー)から選ぶ。絵は decorations/ の花をそのまま入れる(揺れる動きもそのまま)
  - **飾る作品**(最大3つ):飾っている作品を並べ、**長押しして動かすと置き場所が入れ替わる**(フェーズ3のドラッグ並び替えと同じ動かし方。1つ目=床の右、2つ目=ラグの左手前、3つ目=窓辺。各行に置き場所の名前を出す)。「はずす」ボタン。下に、飾っていない小物やインテリアの完成作品と「飾る」ボタン(3つ飾っているときは押せない)
  - 変えたものはその場で保存
- 部屋の色の変数は、部屋の絵の外側の入れ物に付ける。そのために、メモリの中で `room_template.svg` の一番外の style(見本の色)を外す(ほかは変えない)

## 7. 音声入力の仕上げ
フェーズ1で、ホーム画面に追加した iPhone で動くことを確かめた前提です(→ 確認したいこと 5)。
- **数える言葉を変えられるようにする**(設定画面)
  - 今の言葉をチップで並べ、「×」で消す(最後の1つは消せない)。入力欄+「足す」で増やす(ひらがな・カタカナ。16px以上)
  - 「あみ」を入れているときは、今までどおり「アミ」「編み」「網」と聞き取られても数える(聞き取りの漢字・カタカナの揺れのため)
  - 「10目」などの一気入力は今までどおり
- 編む画面は、音声を始めるときに設定の言葉を渡す。`voice.ts` は「言葉を受け取って `countFromTranscript` に渡す」1か所だけ変え、聞き取り・つなぎ直し・オン/オフの仕組みは変えない。`voiceParse.ts` は変えない(すでに言葉を受け取れる形になっている)
- 確かめ用の欄(聞き取った文字・状態)は今のまま残す

## 8. 完成・編みかけに戻すとのつながり
- **完成したとき**:その部門でまだ何も身につけていなければ、そのまま身につける。小物やインテリアは、飾っている作品が3つ未満なら空いている置き場所に飾る(→ 確認したいこと 4)
- **編みかけに戻したとき**:その作品を身につけていれば外す。飾っていればはずす(あとの作品は前に詰める)
- 完成記録の「ひつじが もらってくれました」の下に「パートナーの画面で身につける / 部屋に飾る」への小さなリンク

## フェーズ4の終わりに伝える、iPhoneでの確認手順(短く)

## 確認したことへの答え(OKずみ)
1. 素材のフォルダ:計画どおり `assets/wear/`・`docs/mockups/` に移す(中身は変えない)
2. 体の色・目の色:案のとおり(体8色、目5色、ひつじの目は4色)

4. 自動で身につける・飾る:計画どおり自動。フェーズ3までに完成した作品にも、データを直すとき(3→4)に同じ決め方で身につけ・飾る

   - 飾る作品も、3つを超えるときは完成した日の新しい順に3つまで(いちばん新しい作品が1つ目=床の右)
5. 音声入力:ホーム画面のアプリで「あみ」で数えられることを確認ずみ。7の「数える言葉を変えられるようにする」を入れる
6. 名前:パートナーの画面に名前の欄を付ける(任意、16px以上、その場で保存)
   - 名前があるときは、動物名の代わりに名前を出す:なかまのカード・パートナーの画面・完成記録の「○○が もらってくれました」・編む画面のタブと「○○は『…』を編んでいます」・ホームの作品カード・アルバムの絞り込みとカードなど、パートナーを呼ぶところ
   - 空のときは今までどおり動物名。部門の担当を選ぶカード(新しく編む)は、動物名の下に名前を小さく添える
