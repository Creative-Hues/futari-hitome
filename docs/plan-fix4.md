# 修正4「ひつじの足と、かぎ針を持つ手」計画

## Context
- `assets/animals/sheep.svg` は差し替え済み(まだコミットしていない)。前との差は**足だけ**:体の後ろにあった棒の足(rect 2本+黒い楕円)を消し、体の前に「前に出した足」(楕円・線・光の点 ×2、(99,204) と (141,204))を足してある。頭の毛・体・手・編み針は前と同じ
- `assets/tools/crochet_hook.svg`(新しい素材。まだコミットしていない):`<g id="crochet-right"><g class="crochet-hook">…</g></g>`。どうぶつと同じ 240×240・同じ位置で重ねる
- 見本:`docs/mockups/sheep-legs.png`(左=足を前に・棒針/右=かぎ針)、`docs/mockups/crochet.png`(ひつじ以外の5匹のかぎ針)
  - crochet.png の「ひつじ かぎ針」は棒針のままの絵なので、ひつじのかぎ針は **sheep-legs.png の右**を正とする(→ 確認したいこと 3)

## 今のアプリで確かめたこと
- どうぶつの絵は `src/data/animals.ts` が `assets/animals/*.svg` をそのまま読み込み、`<Partner>` だけが使っている(ホーム・編む画面・お祝い・完成記録・アルバム・なかま・パートナーの画面・部屋の模様替え・新しく編む)。→ **sheep.svg を差し替えるだけで、ひつじを使うすべての画面が新しい足になる**
- 下ごしらえ(`src/lib/partnerSvg.ts`)で、新しい足が今の仕組みとぶつからないこと:
  - 影は「fill が #000 の楕円」で見つけている → 足は #4a4350 なので影と間違えない
  - ひつじの手のまとめ直し(`regroupHands`)は、(102,150)(138,150)の手と (79,169)(161,169)の玉を座標で探している → 足の楕円 (99,204)(141,204)(94,200)(136,200) とは重ならない
  - 体の色は白い毛のグラデーション・編み目だけに付く → 足は黒のまま(SPEC の「ひつじの黒い顔と足は変えない」のとおり)
  - 足は体の一部として「呼吸」のまとまりに入る(前の足と同じ)
- ひつじが身につけられるのは帽子(頭)だけ。帽子は頭の上なので足とは重ならない(くつしたはオコジョとラッコだけ)
- 手の絵:5匹は `rotate(0 102 150)` / `rotate(0 138 150)` の g に「編み針の線2本 → 赤い玉 → 手」の順。ひつじは下ごしらえで同じ並びにまとめ直している
- 手に持つ道具は修正3で `Partner` が決めている(`usedTool`:`tool` を渡された画面はその作品の編み方、なければ `look.tool`=その子が今編んでいる作品、なければ棒針)。今は新しい絵(PNG)の手を選ぶのにだけ使い、SVGの絵には使っていない
- 手袋(ねこ・ラッコ)は、手のまとまりの中・手の絵のあとに入る(手と一緒に回る)
- データの形は変わらない → **データのバージョンは7のまま**

## 1. ひつじの足
- コードは変えない。差し替え済みの `sheep.svg` をそのままコミットする
- テストを足す:ひつじの絵に足(4つの楕円)があり、手(.pt-hand-l / .pt-hand-r)・影には入らず、呼吸のまとまりの中にあること

## 2. かぎ針を持つ手(SVGの絵)
- `src/data/animals.ts` に、`assets/tools/crochet_hook.svg` を文字として読み込む(中身は変えない)
- `partnerSvg.ts`:`PartnerSvgInput` に `tool?: KnitTool`(なければ棒針)を足す。手の目印を付けたあと(ひつじはまとめ直したあと)、かぎ針なら
  - **右の手**(.pt-hand-r):編み針(線2本)と赤い玉を取り除き、その場所(=手の絵の前、下の層)に `crochet-right` の中身(`g.crochet-hook`)を入れる。手の絵がかぎ針の上に重なり、握っているように見える
  - **左の手**(.pt-hand-l):編み針と赤い玉を取り除き、手だけにする
  - 取り除く部品は「線(line)と赤い玉(fill #e45864 の円)」で見分ける。見つからないときは絵を出さずに止まらないよう、今の `regroupHands` と同じくテストで6匹とも確かめる
- かぎ針も手のまとまりの中なので、**編む・ほどく・お祝いの動きは今の CSS のまま手と一緒に回る**(回転の中心 102,150 / 138,150 はそのまま。tokens.css も変えない)
- 手袋:手袋は今までどおり手の絵のあとに入るので、かぎ針 → 手 → 手袋 の順に重なる(手袋がかぎ針を握る形)。ねこ・ラッコの手袋で、かぎ針の柄が手袋の外に自然に出ているかを画像で確かめる
- `Partner.tsx`:下ごしらえに `tool: usedTool` を渡し、絵を作り直す条件に `usedTool` を足す。**どの手にするかの決まりは修正3のまま**(編む画面・ホームの作品カード・お祝い・完成記録・アルバム・新しく編むの選択肢はその作品の編み方/パートナーの画面・なかま・部屋はその子が今編んでいる作品、なければ棒針)
  - 編む画面のメモで編み方を選び直したときも、その場で絵が替わる
- 新しい絵(PNG)の子(修正3。今は `assets/art/` が空なので、公開されるアプリには関係しない):
  - 手のPNGがない子 → 今のSVGの手を使うので、かぎ針の作品ではこの修正のかぎ針の手になる
  - 棒針の手のPNGはあるが、かぎ針の手のPNGがない子 → 修正3の決まりのまま棒針のPNGの手(→ 確認したいこと 2)
