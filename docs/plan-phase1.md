## Context

## 技術の選び方
- **Vite + Preact + TypeScript**。`npm run build` で `dist/` に静的ファイルが出て、Cloudflare Pagesにそのまま置ける。画面が8つまで増えるので、素のJSよりコンポーネントで分けておく(Preactは約4KBと軽い)
- **vite-plugin-pwa**:manifest と service worker(Workbox)をビルド時に作る。オフラインで動く。外部サービスは使わない
- **idb**(IndexedDBを扱いやすくする小さなライブラリ)
- **フォント**:Zen Maru Gothic を `@fontsource/zen-maru-gothic`(500/700)でアプリ内に同梱。フォント自体はGoogle Fontsと同じもので、オフラインでも表示でき、外部への通信も出ない(フォントファイルは初めて使うときにキャッシュ)
- **テスト**:vitest でカウントの計算(段の自動送り・+N・ほどく・取り消し)を確かめる
- 絵は assets/ のSVGを `import` して、そのまま使う(ビルドで名前にハッシュが付くだけで、中身は変えない)

### カウントの動き
- **どこでもタップ**:指が離れた時点(`pointerup`)でカウント。2本目の指が触れる前に1本目を数えてしまわないようにするため(実装時に変更)。ダブルタップでの拡大や文字選択は止める。押した感が分かるよう、「＋1」が小さく浮かぶ
- **誤タッチ防止**(編みながら手のひらや指が触れても数えないように)
  - 指が2本以上触れているときは数えない(触れている指を数え、2本目が触れた時点でそのタッチは無効。全部離れるまで数えない)
  - 前のカウントから0.15秒以内のタッチは同じ1回とみなして数えない
  - この2つの数字(同時に触れてよい指の数=1、まとめる時間=150ms)は `src/config/tuning.ts` の1か所にまとめ、ここを書き換えるだけで変えられるようにする(色や動きの設定を `tokens.css` 1か所にまとめるのと同じ考え方)
  - テスト:2本指・0.15秒以内の連続・0.15秒をあけた連続、の判定を vitest で確かめる(判定は `src/lib/tapGuard.ts` に画面と切り離して置く)
- **段の自動送り**:1段の目数がある作品は、目数が満ちると段+1・目数0に。ない作品はタップで段を数える
- **＋N**:下から出るシートで数を入れる。よく使う数をボタンとして登録・削除できる(最初は10。設定データに保存)。ボタンの表示は一番よく使う数(例「＋10」)
- **取り消し**:直前の操作を1つずつ戻す。操作前の状態を作品ごとに直近50件まで保存
- **ほどく**:シートで「目」か「段」と数を選んで戻す。取り消しとは別ボタン。ほどいた操作も取り消しで戻せる
- 0より下には戻らない。目標の段数を超えても数え続けられる(完成ボタンはフェーズ3)
- **スリープ防止**:編む画面を開いている間 Screen Wake Lock。アプリに戻ってきたとき(`visibilitychange`)に取り直す

### 音声入力の試作
- 「音声」ボタンで開始/停止。`webkitSpeechRecognition`(日本語・連続認識)を使う
- **数えるのは聞き取りが確定した文字(最終結果 `isFinal`)だけ**。確定した文字に「あみ」が入っていたら1カウント(回数分)。「10目」「じゅうめ」のような言い方は一気入力
- 途中の仮の文字(途中結果)は、確かめ用の欄に薄い色で表示するだけで、カウントには使わない。同じ確定結果を二重に数えないよう、処理済みの結果の番号を覚えておく
- 勝手に止まったら自動でつなぎ直す
- **確かめやすくするため**、音声モード中は編む画面に小さな欄を出し、「聞き取った文字」と「状態(聞いています/止まりました/使えません+理由)」を表示する。これでホーム画面版で動くか・どこで止まるかが分かる
- 使えない端末ではボタンを押すと「この端末では使えません」と出るだけ。ほかの機能には影響しない
- 数える言葉は「あみ」で固定(言葉を変える設定はフェーズ4)

### 保存(IndexedDB)
- DB名 `futari-hitome`。フェーズ1で使う入れ物は `works`(作品。今の段数・目数、取り消し用の履歴も作品に持たせる)と `settings`(＋Nの登録数、データのバージョン番号)
- データのバージョン番号 `dataVersion: 1` を持たせ、読み込み時にバージョンを見て古い形を新しい形に直す仕組み(`migrate`)を最初から用意する。パートナー・写真・部屋の入れ物は使うフェーズで追加する
- 作品の項目は SPEC の「データ構造」に沿う(ID・作品名・部門・種類名・パートナー・状態・並び順・色・目標・今の段数/目数・始めた日など)。後のフェーズの項目は、使うときに足す
- カウントのたびにすぐ保存(アプリが急に閉じても消えない)

### PWAとiPhone対応
- manifest(名前・縦画面・standalone・背景色 #fbf7f2)、apple-touch-icon、`viewport-fit=cover` とノッチ・ホームバー部分の余白
- アイコンは**仮**:`sheep.svg` をそのまま #fbf7f2 の背景に置いてPNGにしたもの(ビルド前に一度だけスクリプトで作る。正式なアイコンはフェーズ5)
- タップする場所はすべて44px以上
- `public/_headers` で service worker が古いまま残らないようにする(Cloudflare Pagesの設定ファイル)

## 修正1(iPhoneで試したあとの3点)

### 1. ダブルタップ・2本指での拡大を止める
Safariとホーム画面のアプリ、どちらでも効くよう、次の4つを組み合わせる。
- **CSS**:すべての要素に `touch-action: manipulation`(ダブルタップ拡大と2本指の拡大を止め、ふつうのタップとスクロールは残す)。タップ場所は今のまま `touch-action: none`
- **viewport**:`maximum-scale=1, user-scalable=no` を足す(ホーム画面のアプリではこれが効く。Safariでは無視されることがあるので、ほかの対策も合わせる)
- **2本指の拡大**:`gesturestart` / `gesturechange` / `gestureend` を止める(iPhoneのSafari専用の動き)
- **念のための対策**:ボタンや入力欄以外の場所で、0.3秒以内に2回触れたときは、2回目の `touchend` の標準の動き(拡大)を止める。ボタンは対象外にして、取り消しを続けて2回押すような操作は今までどおり効くようにする。タップ場所は指が離れたとき(`pointerup`)に数えているので、この対策で数がずれることはない
- **文字を入力する欄(input・textarea・select・文字を編集できる場所)には、拡大を止める対策を効かせない**。欄をタップしても文字が打てなくなるのを防ぐため
- **カウントする場所を素早く続けてタップしても、今までどおり1回ずつ数える**(0.15秒より間があいていれば1回ずつ。0.15秒以内は誤タッチ防止で1回にまとめる、は今までどおり)。修正後に、続けてタップしたときの数をテストで確かめる
- 文字入力欄の文字は16px以上のまま(入力欄を触ったときの自動拡大を防ぐ)
- 置き場所:`src/lib/noZoom.ts` を作り、`main.tsx` で1回だけ呼ぶ

### 2. 音声入力のオン・オフをひと目でわかるようにする
- **ボタンの見た目**
  - オフ:白いボタンに「音声」
  - オン:ピンク(#f2a6b4)のボタンに「音声を とめる」(2行)。左上に小さな点が点滅して「聞いている」ことを示す(点滅の速さは tokens.css で変えられる)
- **オンのとき**は、タップ場所の中の確かめ用の欄にも「音声オン」と出す
- オンのときにもう一度押すとオフ
- **自動でオフにするとき**
  - 編む画面から離れたとき(今もそうしているが、確実に止まるよう整理する)
  - アプリを閉じたとき・ほかのアプリに切り替えたとき・画面が消えたとき(`visibilitychange` で見えなくなったとき、`pagehide`)
  - 戻ってきても勝手にはオンにならない(もう一度押してもらう)
- マイクが許可されていないなど、続けられないエラーのときもオフに戻す。理由はボタンの下の小さな文字に「音声:マイクが許可されていません」と出す(次にボタンを押すと消える)

### 3. アプリのアイコンを正式なものに差し替える
- **元の素材は assets/app-icon/ のまま使う**(描き直さない、色や形も変えない)。コピーして中身が2つにならないよう、ビルドのときに assets/app-icon/ のファイルを `dist/icons/` へそのまま出す小さな設定を vite.config.ts に足す
  - apple-touch-icon.png(180×180)→ iPhoneのホーム画面用
  - icon-192.png / icon-512.png → manifest
  - icon.svg → ファビコン
- 仮アイコンを消す:`public/icons/`、`scripts/make-icons.mjs`、`npm run icons`、仮アイコンを作るための @resvg/resvg-js
- **iPhoneが古いアイコンを覚えている対策**:アイコンのアドレスに `?v=2` を付けて、別のファイルとして読み直させる
- manifest の maskable 指定(Androidで丸く切り抜く用)は、余白が足りず絵が欠ける心配があるので外す。iPhoneでは使われない

### 確かめ方
- `npm test`、`npm run build` が通る
- PCのChrome(iPhoneの画面サイズにした状態)で、ビルドした dist/ にアイコン4つがそのまま入っていて、元の素材とまったく同じ中身であること(ファイルの中身を比べる)、manifest とファビコンがそれを指していることを確かめる
- 音声:ボタンを押すとピンクの「音声を とめる」になる、もう一度押すと戻る、画面を離れる・タブを隠すとオフになる
- ダブルタップでの拡大はPCでは再現できないので、iPhoneで確かめてもらう

### iPhoneでホーム画面のアイコンを新しくする手順(公開後に伝える)
- **注意**:ホーム画面のアプリを削除すると、アプリの中のデータ(作った作品と数)も消える。今は試しのデータなので消えてかまわない前提(書き出し機能はフェーズ5)

3. 共有 →「ホーム画面に追加」。追加画面に新しいアイコンが出ていることを確かめてから「追加」
4. まだ古いときは、設定アプリ → アプリ → Safari →「詳細」→「Webサイトデータ」で pages.dev を削除してから、2〜3をやり直す
