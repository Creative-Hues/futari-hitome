# ふたりひとめ 絵の作り方ガイド(画像AI+パーツ分け)

今の図形の絵を、画像AIで描いたイラストに差し替えるためのガイドです。
創がAIで描き、パーツに分けて、透明PNGで書き出します。アプリ側は、新しい絵があればそれを使い、まだない部品は今の絵のまま出します(少しずつ差し替えられます)。

---

## 1. 描く順番(大事な順)

| 順 | 描くもの | 数 |
| --- | --- | --- |
| 1 | どうぶつ6匹(体・目・手と道具) | 6匹 |
| 2 | 頭飾り | 10種類 |
| 3 | 身につける作品(帽子・マフラー・セーター・手袋・くつした) | 10通り |
| 4 | 部屋に飾る作品(クッション・ブランケット・あみぐるみ) | 3種類 |
| 5 | 背景(原っぱ・部屋) | 2枚(あとでよい) |

まずは **ひつじ1匹だけ** を最後まで作り、アプリで動かして確かめてから、残りに進むのがおすすめです。

---

## 2. どうぶつの共通ルール

- **キャンバス**:960×960 px の正方形、背景は透明
- **位置**:6匹とも同じ場所・同じ大きさ。下敷き画像 `guide_<どうぶつ>.png` を一番下のレイヤーに置いて、合わせて描く(置く)
  - 足もとの線:y=856
  - 体の真ん中:x=480
  - 胸の前(赤い点線の四角。x=416〜544)に、編み地が入る。編み地は上の端 y=584 が動かず、進み具合で下に伸び、いちばん長いと y=760 まで(四角はいちばん長いときの大きさ)
  - 手の回転の中心(赤い丸)に、左右の手を合わせる
  - 頭飾りの位置(緑の丸)は、頭のてっぺんの真ん中
- **影**:足もとの影(地面の楕円)は描かない。影はアプリが描く(体に入れると、呼吸やジャンプで影も一緒に動いてしまうため)
- **ポーズ**:正面を向いて座り、胸の前で両手を上げて編んでいる
- **絵柄**:6匹とも同じプロンプトの型で描き、絵柄をそろえる(下の「5. プロンプトの型」)
- **今の特徴は残す**:正円の目を離して置く、ピンクのほっぺ、「ω」の口、体はあみぐるみの編み目(体だけ、顔には入れない)。各どうぶつの特徴は SPEC.md の「6匹の特徴」

---

## 3. どうぶつのパーツの分け方

1匹につき、次のファイルを作ります(`sheep` の部分はどうぶつ名:sheep / cat / stoat / axolotl / seal / otter)。

| ファイル | 中身 | 注意 |
| --- | --- | --- |
| `sheep_body.png` | 体・顔・耳・しっぽ・足(目と手は消して、まわりの色で埋める) | ほっぺ・鼻・口・ひげはここに入れる |
| `sheep_body-mask.png` | 体の色を変える場所を白、それ以外を黒(または透明) | 下の「4. 色の変え方」 |
| `sheep_eyes.png` | 目だけ(2つとも) | まばたきで縦につぶすので、目だけを切り出す。2つの目は同じ高さに |
| `sheep_hand-left_knit.png` | 画面の左の手+棒針1本 | 回転の中心(左の赤い丸)が手のひらの真ん中に来るように |
| `sheep_hand-right_knit.png` | 画面の右の手+棒針1本 | 同上(右の赤い丸) |
| `sheep_hand-left_crochet.png` | 画面の左の手(編み地を持つ手。道具なし) | かぎ針のとき用 |
| `sheep_hand-right_crochet.png` | 画面の右の手+かぎ針 | かぎ針のとき用 |

- 手のファイルもキャンバスは960×960で、手のある場所以外は透明にする(位置を動かさない)
- 棒針とかぎ針で、手(手のひら)の形と位置は同じにし、ちがうのは道具だけにする(手袋の絵を1枚で両方に使うため)
- 編み地はアプリが描くので、絵には入れない(胸の前の四角は空けておく。手と道具は四角の上に重なってよい)
- 頭飾りは別ファイルなので、頭には何も乗せない

## 4. 色の変え方(大事)

アプリは「白っぽく描いた部分に、選んだ色を掛け合わせる」方法で色を変えます。
- **どうぶつの体**:体はこれまでどおり白で描く。`body-mask.png` で白くした場所にだけ、選んだ体の色が付く
  - ひつじは、白い毛の部分だけを白にする(黒い顔と足は黒のまま)
  - ほっぺ・鼻・目・ウーパールーパーのエラなど、色を変えない部分は黒(または透明)にする
  - 輪郭線は黒にする(白にすると輪郭線にも色が付く)
  - 白と黒の境目のぼかし(灰色)はあってよい。灰色のところは、その割合だけ色が付く
  - 白い場所は、体の絵の内側だけにする(体の外にはみ出さない)
- **目**:`eyes.png` は形だけ使い、アプリが選んだ目の色でそのまま塗る(もとの色は、ひつじは白、ほかは黒)。目は何色で描いてもよい。光の点などは入れず、塗りつぶした正円で描く。2つの目は同じ高さに
- **身につける作品・部屋に飾る作品・編み地**:白〜うすいグレーだけで描く(色を付けない)。アプリが作品の色を掛け合わせる。輪郭線は濃いグレーでよい

## 5. プロンプトの型

絵柄をそろえるため、どの絵も同じ型の文で描きます。`[ ]` の中だけを入れ替えます。

```
cute amigurumi-style [white cat] plush, crocheted texture on the body only (no texture on the face),
sitting, facing front, both paws raised in front of the chest as if knitting,
small round solid black eyes set wide apart, pink cheeks, small "ω" shaped mouth,
soft pastel colors, gentle hand-drawn outline in muted purple-gray,
simple children's picture book illustration, flat soft shading,
full body, centered, plain white background, no props, no text
```

- どうぶつの特徴を `[ ]` に入れる(例:`fluffy white sheep with a black face and black legs, a tuft of white wool on the head`)
- 道具(棒針・かぎ針)は手と一緒に描くと崩れやすいので、手と道具だけを別に描いて切り出してもよい
- 頭飾り・身につける作品も、同じ型の後半(`soft pastel colors` から)をそのまま使う

## 6. 頭飾り・身につける作品・部屋に飾る作品

| 種類 | ファイル名 | キャンバス | 位置 |
| --- | --- | --- | --- |
| 頭飾り(10) | `deco_tulip.png` など(今の名前と同じ) | 272×272 | 下の真ん中(x=136, y=247)が頭に触れる点 |
| 身につける作品(10) | `wear_head_sheep.png` など(今の名前と同じ) | 960×960 | そのどうぶつの体にぴったり重なる位置。手袋は `wear_paws_cat_left.png` と `_right.png` に分け、手のファイルと同じ位置 |
| 部屋に飾る作品(3) | `room_cushion.png` など | 288×232 | 下の真ん中(x=144, y=208)が床に触れる点 |

- 頭飾りは今のものと同じ色で描いてよい(色を変えない)
- 頭飾りのPNGは、頭の上のほか、部屋の窓辺の鉢植えの花と、頭飾り・花を選ぶ画面の小さな絵にも使う
- 身につける作品と部屋に飾る作品は、白〜うすいグレーで描く(上の 4)

---

## 7. 書き出し

- 形式:PNG(背景は透明)
- 置き場所:`assets/art/` の中に、上のファイル名のまま入れる
- 置いたら `npm run art`(`npm run dev` / `npm run build` の前にも自動で動く)で、アプリで使う軽い版ができる。元の絵は変えない
- 位置がずれたときは、`assets/art/art.json` の数字で直す(頭飾りの位置・帽子のときの頭飾りの高さ・手の回転の中心・編み地の場所・頭飾りが頭に触れる点・部屋に飾る作品が床に触れる点)
  - 数字の単位は、このガイドと同じ **キャンバスの点(px)**。どうぶつ・身につける作品は 960×960、頭飾りは 272×272、部屋に飾る作品は 288×232 のキャンバスの点で書く
  - 書き方と項目の一覧は `assets/art/README.md`
