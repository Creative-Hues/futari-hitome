# フェーズ3「作品の管理と記録」計画

## Context
フェーズ2は iPhone で確認ずみ(パートナーの動き・ふれあい・空の時間帯・フェーズ1の動き)。「始めの編み地が小さい」「夜にパートナーが浮く」はこのままでよい。
今は、作品は何個でも作れるが、編む画面は1作品ずつで、完成させる手段がない。ホームの一覧は新しい順に並ぶだけ。

フェーズ3の範囲(SPEC.md より)
- 複数作品の同時進行とタブ切り替え(同じ子のワンタップ切り替えも)、2つ目のカウンター、作品メモと編み図の写真、完成の演出、完成記録、作品アルバム
- あわせて:ホームの一覧のドラッグ並び替え(フェーズ1で「フェーズ3で入れる」としたもの)、編んだ時間の目安(完成記録に必要)、`navigator.storage.persist()`

入れないもの:身につける・部屋に飾る(フェーズ4。もらった子はデータに残すだけ)、なかま画面・パートナーの画面・頭飾りの付け替え(フェーズ4)、設定画面と歯車・音声の言葉の変更(フェーズ4)、書き出し・読み込み・ヘルプ(フェーズ5)。下のメニューは「ホーム」「アルバム」の2つだけにし、「なかま」はフェーズ4で足す。

## 1. データが消されにくくする(persist)
- `src/lib/persist.ts`:アプリを開いたときに `navigator.storage.persisted()` を見て、まだなら `navigator.storage.persist()` を呼ぶ。使えないブラウザでは何もしない(ほかの動きに影響しない)
- 写真を初めて保存したときにも、まだ許可されていなければもう一度呼ぶ
- 結果はアルバムの一番下に小さく出す:「記録と写真はこの端末の中に保存しています」+ 許可されていれば「(消されにくい設定:オン)」。iPhone で効いているかを確かめるため
- ヘルプでの書き出しのすすめはフェーズ5

## 2. 複数作品の同時進行とタブ
- **編む画面の上のタブ**(Knit.mock.html の見た目):編みかけの作品が2つ以上のときに、戻るボタンの横に並ぶ。1つのときは今までどおり作品名を出す
  - 文字は「種類名・どうぶつ名」(例「マフラー・ひつじ」)。同じ文字のタブが2つあるときは作品名にする
  - 3つ以上は横にスクロール。タブの高さは44px以上。並びはホームの一覧と同じ
  - タブを押すとその作品の編む画面に切り替わる(戻るでホームへ。タブの切り替えは履歴に積まない)
  - **切り替えたときは音声をオフにする**(別の作品に数えてしまう間違いを防ぐため。「編む画面から離れたらオフ」と同じ扱い)。スリープ防止は続く
- **同じ子のワンタップ切り替え**
  - パートナーごとに「今編んでいる作品」を持つ。新しく作った作品は、その子の「今編んでいる作品」になる
  - その子が別の作品を編んでいる作品の画面では、原っぱのパートナーはその別の作品(色・長さ)を編んでいる。原っぱの下のほうに小さく「ひつじは『青いマフラー』を編んでいます」と「こっちを編む」ボタン(44px以上)を出す
  - その作品でも数えられる(数は増える)。手は動かない(別の作品を編んでいるため)
  - 「こっちを編む」を押すと、編み地の色が変わり、高さがこの作品の進み具合までなめらかに伸び縮みする(=追いつく)。以後は数えると手が動く
  - ホームの部屋の子も「今編んでいる作品」を持って出る。作品カードの小さな絵は今までどおりその作品のまま
- **ホームの一覧のドラッグ並び替え**(下の「7. ドラッグ並び替え」)

## 3. 2つ目のカウンター(模様など)
- 編む画面の数字の横に、試作どおりピンクの小さなチップ「模様 10回」。まだ使っていない作品は薄いチップ「＋ 2つ目」
- チップを押すとシート:名前(最初は「模様」)・＋1回 / −1回・「○段ごとに1回 自動で進める」(入れなければ手で数える)・「使わない」
- 自動のとき:段が○段進むごとに1回進む。ほどく・取り消しで段が戻ると一緒に戻る。0より下にはならない
- 手で＋1/−1した分も「取り消し」で戻せる(数と模様をまとめて1つの操作として残す)
- 段の自動送り・＋N・ほどく・取り消しの計算(counter.ts の今の関数)は変えず、模様の進め方は別の関数として足してテストする

## 4. 作品メモと編み図の写真
- 編む画面の下のボタンを5つにする(試作どおり「取り消し / ＋10 / ほどく / 音声 / メモ」)
- 「メモ」で高めのシートが開く(編む画面のまま。スリープ防止も続き、シートの間はタップ場所に触れない):
  - 使った毛糸・針の号数・自由メモ(入力をやめた少しあとと、閉じたときに保存)
  - 編み図の写真:「カメラで撮る」「写真から選ぶ」の2つのボタン。並びはドラッグで変えられる。写真を押すと大きく見る画面
  - 大きく見る画面:幅いっぱいに表示し、「1倍 / 2倍 / 3倍」のボタンで大きくして、指でスクロールして見る(2本指の拡大は、拡大防止の仕組みを変えないため使わない)。削除は確認してから
  - 一番下に「この作品を完成にする」
- **写真の取り込み**(`src/lib/photo.ts`)
  - 「カメラで撮る」:`<input type="file" accept="image/*" capture="environment">`。「写真から選ぶ」:`accept="image/*" multiple`(写真ライブラリから複数選べる)
  - 読み込んだ写真を、長辺1600pxまで縮小した JPEG(画質0.85)にして保存。一覧用に長辺400pxの小さい版も一緒に作る。元の写真は保存しない
  - 写真の向きは iPhone で撮ったとおりになるようにする(縦向きの写真が横にならない)
  - 読めない写真は「この写真は読み込めませんでした」と出して、ほかの写真は続けて保存する
  - 縮小する長辺・画質は `src/config/tuning.ts` に足す(今ある値は変えない)

## 5. 完成の演出と完成記録
- **完成ボタン**:目標がある作品は、達成率が100%になったら数字の横にピンクの「完成!」ボタンが出る。目標なしの作品は「だいたい 100%」にしたときに出る。どの作品でもメモのシートの一番下から完成にできる
- 押すと「完成にしますか?」の確認(押し間違い用)→ すぐに保存:状態を完成に・完成した日・**もらった子(その作品のパートナー)**。ここで保存するので、演出の途中でアプリを閉じても消えない
- **お祝い**(編む画面の上に重ねる。タップ場所は隠れるので数えない)
  - パートナーの編み地が一番上まで伸び、ぴょんぴょん数回跳ねて、左右にゆれ、頭飾りが大きく揺れる。吹き出し「できたね!」
  - まわりに小さな丸の紙吹雪(作品の色・ピンク・青)がふわっと落ちる
  - 動きはフェーズ2と同じ仕組み:Partner の目印(`.pt-react` など)に CSS アニメーションを付けるだけ。**速さ・跳ねる高さ・回数・紙吹雪の数と落ちる速さは tokens.css の「動き」の欄**に足す(`--celebrate-…`)。「視差効果を減らす」がオンのときは跳ねずに短く
  - 「記録をつける」ボタンで完成記録へ。「あとで」でホームへ(記録はアルバムからいつでもつけられる)
- **完成記録の画面**(`#/record/:id`)
  - 写真(複数。カメラ/写真ライブラリ。ドラッグで並び替え。1枚目がアルバムの表紙)
  - 感想(自由入力)
  - 自動で入るもの:始めた日・完成した日・かかった日数(同じ日なら1日)・編んだ時間の目安・最終の段数と目数(と模様の回数)・作品メモ(毛糸・針・メモ・編み図の写真)
  - 「ひつじが もらってくれました」の一文(もらった子の記録。身につける・飾るはフェーズ4)
  - 入力した分はその場で保存
- **編んだ時間の目安**(`src/lib/knitTime.ts`):編む画面で数が変わるたびに、前に数が変わったときから5分以内ならその間の時間を足す(5分より空いたら、休んでいたとみなして足さない)。5分は tuning.ts に。フェーズ3より前に編んだ分は入っていないので、古い作品は短めに出る

## 6. 作品アルバム
- 下のメニューに「アルバム」(試作のアイコン)。ホームとアルバムの画面に出す(編む画面には出さない)
- `#/album`:完成した作品を、完成した日の新しい順に2列のカードで並べる(表紙の写真、なければその作品の色で編むパートナーの絵/作品名/完成した日/どうぶつ名)。並びは日付順で、手で並び替えるものではないのでドラッグはなし
- 上にパートナーごとの絞り込み(「すべて」+完成した作品がある子)
- カードを押すと `#/album/:id`:完成記録の中身をすべて表示。「記録を直す」で完成記録の画面へ
- 一番下に、上の persist の一文

## 7. ドラッグ並び替え
- 対象:ホームの編みかけの作品(タブの並びも同じになる)、編み図の写真、完成写真
- 動かし方:項目を**少し長押し(0.35秒)すると持ち上がり**、そのまま指を動かして好きな位置で離す。長押しする前に指が動けばふつうのスクロール、すぐ離せばふつうのタップ(作品を開くなど)。持ち上がったら少し大きく・影を濃くする。画面の端に近づくと自動でスクロール
- 長押しの時間は tuning.ts に。iPhone の長押しメニュー(リンクのプレビュー)が出ないようにする
- 並べ替えの計算は `src/lib/reorder.ts` に画面と切り離して置き、テストする。指の動きは `src/lib/useDragSort.ts`(Pointer Events)にまとめて3か所で使う
- 編む画面のタップ場所とは別の画面・別の要素なので、数え方には関わらない

## 8. 保存(IndexedDB)
- 入れ物 `photos` を追加(ID・どの作品か・種類[編み図/完成写真]・並び順・縮小した画像・小さい版・幅と高さ・保存した日)。作品IDで引けるようにする。DBの版 2 → 3
- 作品に足す項目:2つ目のカウンター(名前・回数・○段ごと)、作品メモ(毛糸・針・自由メモ)、感想、完成した日、もらった子、編んだ時間の目安
- パートナーに足す項目:今編んでいる作品のID
- データのバージョン 2 → 3。直し方:作品に上の項目を空の値で足す(取り消しの履歴も新しい形に)。各パートナーの「今編んでいる作品」は、その子の編みかけのうち最後に数えた作品。フェーズ2までのデータはそのまま読める
- 写真は画像のまま(Blob)保存する。書き出しのときに文字に変換するのはフェーズ5

## フェーズ1・2の動きを変えないために
- **触らないファイル**:`noZoom.ts`(拡大の防止)、`tapGuard.ts`(すばやいタップ・誤タッチ防止)、`voice.ts` と `voiceParse.ts`(音声)、`partnerSvg.ts` と `sceneSvg.ts`(絵の印付け)。`tuning.ts` は値を足すだけで、今の値は変えない
- 編む画面のタップ場所(TapZone)と音声ボタンの中身は変えない。数えたあとに「編んだ時間」「模様」を足すだけ
- パートナーの今の動き(呼吸・まばたき・揺れ・編む・ほどく・ふれあい)の CSS は変えず、お祝いの動きを足す
- 写真の取り込み・ドラッグは編む画面のタップ場所の外(シートと別の画面)だけで動く
- 文字の入力欄は16px以上(入力欄を触ったときの拡大を防ぐ)、タップする場所は44px以上
- 確かめ方:今あるテスト(すばやいタップ・2本指・音声の読み取り・印付け・データの直し方)がそのまま通ること。PC で素早く続けてタップして数がずれないこと。iPhone での確認手順にも入れる

## フェーズ3の終わりに伝える、iPhoneでの確認手順(短く)

3. 模様のチップで「○段ごと」を入れ、段が進むと回数が増えるか、取り消しで戻るか
4. メモ:毛糸・針・メモを入れる。「カメラで撮る」「写真から選ぶ」の両方で編み図を入れ、大きく見る・並び替え・削除
5. ホームで作品を長押しして並び替え。タブの並びも変わるか
6. 作品を完成にする → お祝い → 写真と感想を入れる → アルバムに出るか、パートナーで絞り込めるか
7. **フェーズ1・2の確認**:ダブルタップ・2本指で拡大しないか/すばやく続けてタップして1回ずつ数えるか/音声のオン・オフ(タブを切り替えるとオフになる)/パートナーの動きとふれあい

## 確認したことへの答え(OKずみ)
1. 並び替え:長押し(0.35秒)で持ち上げる
2. 紙吹雪:小さな丸(作品の色・ピンク・青)
3. 「＋N」の登録した数:ドラッグで並び替えられるようにする。一番上の数がボタンに出る形のまま(フェーズ3のドラッグ対象に追加)
4. タブの切り替えで音声はオフにする

## 追加1:編み図の写真を2本指で拡大
- 写真を大きく見る画面の中だけで、2本指の動き(Pointer Events)を読み取り、**写真の大きさと位置を変える**(画面全体の拡大ではない)。1本指で拡大した写真を動かす
- 拡大は1〜5倍。写真が画面の外へ行きすぎないように止める
- 1倍・2倍・3倍のボタンも残す。ダブルタップ(0.3秒以内に2回)で1倍に戻す
- `noZoom.ts` は触らない。この画面の外では今までどおり拡大しない(画面全体のピンチ拡大は今の仕組みで止まったまま)
- 拡大・移動の計算は `src/lib/pinch.ts` に画面と切り離して置き、テストする
- 「大きく見る」は完成写真にも同じものを使う

## 追加2:完成を取り消す(編みかけに戻す)
- アルバムの記録の画面に「編みかけに戻す」。確認してから実行
- 状態を編みかけに戻し、完成した日ともらった子の記録を消す。写真・感想・メモ・数・編んだ時間は残す
- 戻した作品はホームの一覧の一番上に入る。その子の「今編んでいる作品」がなければ、この作品にする

## 確認したいこと(当初)
1. **並び替えの始め方**:長押し(0.35秒)で持ち上げる形でよいか。試作のカードの見た目をそのままにできる。ほかに、カードの端に「つまむ印」を付けてそこを動かす形もできる(見た目に印が増える)
2. **紙吹雪**:素材にないため、星と同じように小さな丸を新しく置く形にしたい(作品の色・ピンク・青)。これでよいか
3. **「＋N」の登録した数**:フェーズ1からある一覧で、今は並び替えられない(一番最初の数がボタンに出る)。これもドラッグで並び替えられるようにするか
4. **タブの切り替えで音声をオフにする**:上の理由でオフにしたいが、続けたほうがよければ、切り替えても音声を続ける形にもできる
