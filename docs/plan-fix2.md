# 修正2「使い勝手の直し」計画

## Context
フェーズ1〜5と追加1は iPhone で確認ずみ。愛海が使ってみて、直してほしいところ(ボタンの文字のはみ出し・戻れない画面・体の色がわかりにくい・2つ目のカウンターがわかりにくい)と、足したい機能(編む画面から編み図を見る・パーツ・棒針/かぎ針)が出てきた。
修正2では、この7つを入れる。新しい絵(PNG)の仕組みは修正3で入れるので、修正2では入れない(かぎ針の作品も今の棒針の絵のまま。データだけ持つ)。

あわせて、創が入れた `docs/art/`(絵の作り方のガイドと下敷き画像)を、修正2のコミットに一緒に入れる(中身は変えない)。

## 今のアプリで確かめたこと
- **ボタンの文字**:「どこにつけるもの?」の部門のボタンは3列で、文字を1行のまま折り返さない作り(`white-space: nowrap`)。320〜390px の幅では「身につけるもの」「小物やインテリア」が入りきらない。編む画面の下の5つのボタン(取り消し/＋10/ほどく/音声/メモ)も 320px では1つ約52px で、「取り消し」がぎりぎり
- **編み図の写真**:今はメモのシートの中の一覧からだけ開ける。大きく見る画面(`PhotoViewer`)には、すでに「前の写真/次の写真」のボタンと「2 / 3」の表示がある(指で左右にはらう動きはない)
- **戻るボタン**:どの画面の戻るボタンも、行き先が1つに決めてある(パートナーの画面 → いつもなかま、編む画面 → いつもホーム、など)。そのため、別の画面から来たときに来た画面へ戻れない
- **体の色**:候補の7色はとても白に近い色(例:さくら #fbe2e8)で、そこからさらに白を混ぜて明るいところを作っているため、ほとんど白に見える。編み目の線と影も、選んだ色をほんの少し(1割ほど)暗くしているだけ
- **数のデータ**:段・目・目標・取り消しの履歴・模様・編んだ時間は、作品に1組だけ持っている。1つの作品の中で1段目に戻る編み方は数えられない
- 体の白に関わる色は、6匹とも同じ作り(`wool` のグラデーション3色・編み目の線・ねこ/オコジョのしっぽの白い線)。ひげ・ラッコの白い口まわりは体の色ではない(変えない)

## 1. ボタン・チップ・タブの文字がはみ出さないようにする

### 直し方の決まり
- 文字を折り返してよいボタン(部門・種類名・目標の選び方など)は、**2行まで折り返す**。行の間をつめ、ボタンの高さは44px以上のまま(2行のときは高さが自然に伸びる)
- 1行のままにしたいボタン(編む画面の下の5つ・タブ・＋N の数など)は、**幅が足りないときだけ文字を少し小さくする**(最小 12px。`clamp()` で画面の幅に合わせる)
- 並びを変えたほうが読みやすいところは並びを変える(例:部門のボタンを3列 → 2列)
- タップする場所は44px以上のまま。文字を入力する欄の文字は16px以上のまま

### 確かめ方(全部の画面 × 3つの幅)
- PC の Chrome を画面なし(ヘッドレス)で動かす小さな確かめ用のスクリプトを作る。**スクリプトと道具(puppeteer-core)は scratchpad(作業用の一時フォルダ)に置き、プロジェクトには入れない**(アプリの中身・package.json は変わらない)
- 作品・パーツ・写真・完成作品・お休みの作品が入った状態をつくり、次の画面を 320px・375px・390px の幅で開く:
  ホーム(お休み中を開いた状態も)/新しく編む(部門ごとの選択肢・パーツを開いた状態)/編む画面(タブあり・パーツあり・音声オン・同じ子の切り替えの帯・完成ボタン)/編む画面の各シート(＋N・ほどく・模様・メモ・パーツ・確認)/完成のお祝い/完成記録/アルバム(絞り込み)/アルバムの記録/なかま/パートナーの画面/設定/部屋の模様替え/ヘルプ/写真を大きく見る画面
- それぞれの画面で、ボタン・チップ・タブ・リンクの**文字が枠の外に出ていないか**と**高さが44px以上か**を自動で調べ、画面写真も残す。見つかった場所を直して、もう一度調べる
- 終わったら、**直した場所の一覧**(画面・場所・直し方)を伝える。画面写真は scratchpad に置き、場所を伝える

## 2. 編む画面から編み図の写真を見る
- 編み図の写真がある作品では、**原っぱの左上に、1枚目の小さな写真(56px の角丸の四角、白いふち)**を出す。写真がなければ出さない
  - 右上は「完成!」、下は「○○は…を編んでいます」の帯、真ん中はパートナー(タップでしぐさ)なので、どれとも重ならない場所
  - 原っぱはタップして数える場所(下半分)とは別の場所なので、押し間違いで数が増えることはない
- 押すと、今の「大きく見る画面」(2本指の拡大・1倍/2倍/3倍・ダブルタップで1倍)が編む画面の上に開く
  - 写真が2枚以上のときは、今の「前の写真/次の写真」のボタンに加えて、**1倍のときに指で左右にはらうと切り替わる**ようにする(拡大しているときは、今までどおり写真を動かす)。はらう長さは `tuning.ts` に足す
  - 編む画面から開いたときは見るだけ(消すボタンは出さない。消すのは今までどおりメモのシートから)
- 見ている間も編む画面はそのまま(画面の上に重ねるだけ)なので、**スリープ防止は続く**。音声がオンなら、見ている間も音声で数えられる
- 閉じると、すぐ数えられる状態に戻る(タップ場所には何も残らない)
- メモのシートで写真を足したり並べ替えたりしたら、シートを閉じたときに小さな写真を新しくする

## 3. 戻るボタンで「来た画面」に戻る
- 戻るボタンは、**アプリの中で来た画面があれば、そこへ戻る**(ブラウザの「戻る」と同じ)。アプリを開いてすぐの画面など、来た画面がないときは、今までどおりの決まった画面へ
- そのために、画面を移るたびに「アプリの中で何画面目か」を覚えておく(`router.ts`)。タブの切り替え・完成から記録へなど、今「置き換え」で移っているところは置き換えのまま(戻る先が増えない)
- 見つけた「戻れない」場所と、直したあとの戻り先:

| 来た道 | 今の戻り先 | 直したあと |
| --- | --- | --- |
| 完成記録 →「パートナーの画面で身につける/部屋に飾る」→ パートナーの画面 | なかま | 完成記録 |
| アルバムの記録 → もらった子のリンク → パートナーの画面 | なかま | アルバムの記録 |
| パートナーの画面 → 一緒に編んだ作品(編みかけ)→ 編む画面 | ホーム | パートナーの画面 |
| パートナーの画面 → 一緒に編んだ作品(完成)→ アルバムの記録 | アルバム | パートナーの画面 |
| アルバムの記録 →「編みかけに戻す」→ 編む画面 | ホーム | アルバム |
| 編む画面 → お祝い →「記録をつける」→ 完成記録 | アルバムの記録 | 編む画面の前にいた画面(ふつうはホーム) |

- パートナーの画面 → お休みの作品 → ホームの「お休み中」は、ホームに戻るボタンがない(ホームは下のメニューの一番上の画面のため)。→ 確認したいこと 3
- ほかの画面(新しく編む・設定・部屋の模様替え・ヘルプ・なかま・アルバム)は、来られる道が1つだけなので、今と同じ戻り先になる

- 前に選んだ色(今の薄い色)が保存されている子は、**同じ名前の新しい色に置き換える**(データの直し方に入れる。下の 8)

## 5. パーツ(手袋の指・右手と左手など)

### 考え方
- 1つの作品の中に**パーツ**を作れる。パーツごとに、名前・今の段数と目数・目標(段数+1段の目数/目標なし)・取り消しの履歴・模様の回数・編んだ時間を持つ
- パーツは**まとまり**(例:「右手」)の中に入れられる(まとまりなしでもよい)。編む画面では「右手・親指」のように出す。まとまりは「右手・左手」のように同じものを複製するための入れ物(→ 確認したいこと 1)
- **パーツを作らない作品は、今までどおり**(中ではパーツ1つの作品として持つ。画面にはパーツの表示を出さない)
- 数える・取り消し・ほどく・＋N・模様・音声・編んだ時間は、すべて**今編んでいるパーツ**に効く(今の数え方の計算 `counter.ts`・`pattern.ts`・`knitTime.ts` はそのまま、パーツの数に対して使う)

### 編む画面
パーツが2つ以上ある作品だけ、進みのバーの上に1行増える:
```
[ 右手・親指  ▾ ]                 [ 次のパーツへ ]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← 今のパーツの進み具合
12 / 20段        5 / 24目        [模様 2回]
```
- 左の**パーツのチップ**(44px以上):押すと「パーツ」のシート
- 右の**「次のパーツへ」**:今のパーツが目標に届いたときに出る(目標なしのパーツは、いつも小さく出す)。押すと、次のパーツの1段目から数え始める(次のパーツに数があれば、その続きから)。最後のパーツのときは出さない(作品全体が目標に届けば、今までどおり「完成!」が出る)
- 数字・バー・模様のチップは、今のパーツのもの。原っぱのパートナーの編み地の高さは**作品全体の進み具合**
- パーツを切り替えたとき、「親指を数えます」と小さく出す(どのパーツに数えているか見落とさないように)。音声はオンのまま(同じ作品なので)。取り消しの履歴はパーツごとなので、切り替えても混ざらない

**パーツのシート**(高めのシート)
- パーツの一覧(まとまりごとに見出し)。各行:名前・「12/20段」・今のパーツの印。押すとそのパーツに切り替えてシートを閉じる
- 下に「作品全体 45%」
- 「パーツを直す」で編集の画面(下)に変わる

### パーツを作る・直す(新しく編む画面と、編む画面のシートで同じ部品)
- 新しく編む画面:目標の下に「パーツ」の欄。「手袋の指や右手・左手のように、1段目に戻って編む部分があるときに分けます。あとから編む画面のメモでも分けられます」と「パーツに分ける」ボタン
  - 分けたときは、目標はパーツごとに入れる(今の「目標」の欄は、最初のパーツの目標として使う)
- あとから:編む画面のメモのシートに「パーツ」の欄(「パーツに分ける」/ パーツがあれば「パーツを直す」)
- 編集でできること
  - **パーツを足す**(まとまりを選ぶ/新しいまとまり/まとまりなし)。名前と目標は小さなシートで入れる。目標は、すぐ上のパーツと同じものを最初から入れておく
  - **名前・まとまり・目標を直す**(数は変えない)
  - **複製**:パーツ1つ、または**まとまりごと**(例:「右手」の指5本をまとめて複製 → 名前を入れて「左手」)。名前は、「右」が入っていれば「左」に、「左」なら「右」に置き換えたものを最初から入れておく(ほかは「○○ 2」)。複製したパーツの数・履歴・模様の回数・編んだ時間は0から、目標と模様の設定(名前・○段ごと)は同じ
  - **並び替え**:まとまりの見出しを長押しで動かすと、まとまりごと動く。まとまりの中のパーツも長押しで動かせる(今までと同じ、0.35秒の長押しで持ち上げるドラッグ)
  - **消す**:確認のシート(「親指の数・取り消しの履歴が消えます。元に戻せません」)。最後の1つは消せない。パーツが1つになったら、今までどおりの表示に戻る

### 作品全体の進み具合
- 各パーツの進み具合(目標あり:達成率、目標なし:そのパーツの「だいたい○%」)を、**目標の段数の重み**で平均する(親指20段と手のひら40段なら、手のひらが2倍効く)。目標なしのパーツは、目標ありのパーツの平均の段数ぶんとして数える。全部目標なしなら、そのまま平均(→ 確認したいこと 2)
- パーツ1つの作品は、今までとまったく同じ計算になる
- 使うところ:パートナーの編み地、ホームの作品カードのバー、パートナーの画面の「編みかけ ○%」、完成ボタンが出るか(全体が100%)
- ホームの作品カードの数は、パーツがあれば今のパーツ(「親指 12/20段」)

### 完成記録
- 「最後の数」に、パーツごとの段数・目数(と模様の回数)を1行ずつ出す(例「右手・親指 20段 ・ 0目」)。パーツなしの作品は今のまま
- 編んだ時間は全パーツの合計

## 6. 2つ目のカウンター(模様)をわかりやすくする
- 名前を「**模様の回数**」にする。まだ使っていない作品のチップは「＋ 模様の回数」(使っているときは今までどおり「模様 10回」)
- 最初のシートの説明:「模様のくり返し回数など、段とは別に数えたいものに使います。『8段ごとに1回』のように入れると、段に合わせて自動で進みます」
- 使っているときのシートに、今の動き方を1行で出す(「8段ごとに自動で進みます」/「＋1回で手で数えます」)
- パーツがあるときは、シートに「このカウンターは『親指』のものです」と出す
- ヘルプ(`src/data/help.ts`)を直す
  - **模様の回数**:模様のくり返しの回数など、段とは別に数えたいものに使います。「○段ごと」を入れると段に合わせて自動で進み、ほどく・取り消しで段が戻ると一緒に戻ります
  - **パーツ**(新しく):手袋の指や右手・左手のように、1つの作品の中で1段目に戻って編む部分を分けて数えます。段・目・取り消し・模様の回数はパーツごと。まとまりごと複製して「左手」を作れます
  - **パーツと模様の回数のちがい**(パーツの項目の中に):パーツは「別々に1段目から数える部分」、模様の回数は「同じところを編みながら、段とは別に数えるもの」
  - あわせて、編み図の小さな写真(「メモと写真」)・棒針/かぎ針(「作品」)・戻るボタンの文を足す

## 7. 棒針・かぎ針
- 新しく編む画面に「編み方」の欄:「棒針」「かぎ針」のチップ。**最初は、前に作った作品(いちばん新しく始めた作品)と同じほう**。作品がまだなければ棒針
- 編む画面のメモのシートで選び直せる(その場で保存)
- 完成記録・アルバムの記録の「作品」の行に「かぎ針」などと出す
- 修正2では絵は変えない(かぎ針の作品も今の棒針の絵)。かぎ針を持つ手は修正3で入れる

## 8. データ(IndexedDB)
- 入れ物は増えない(DB の版は 4 のまま)
- 作品の形を変える。**データのバージョン 6 → 7**
  - 作品に `parts`(パーツの並び)・`currentPartId`(今編んでいるパーツ)・`tool`(`'knit'` 棒針 / `'crochet'` かぎ針)を足す
  - パーツ:`id`・`group`(まとまりの名前、なしは空)・`name`・`goalRows`・`stitchesPerRow`・`count`・`manualProgress`・`history`・`pattern`・`knitMs`
  - 作品にあった `goalRows`・`stitchesPerRow`・`count`・`manualProgress`・`history`・`pattern`・`knitMs` は、1つ目のパーツへ移す(作品からはなくす。同じ数を2か所に持たないため)。`lastCountAt`(最後に数えた時刻)は作品のまま
  - 直し方(6→7):今の数・目標・履歴・模様・編んだ時間をそのまま1つのパーツにする。`tool` は棒針。パートナーの体の色が今の候補の色なら、同じ名前の新しい色に置き換える(候補にない色はそのまま)
  - フェーズ1〜追加1のデータ・書き出したファイル(バージョン1〜6)は、今までの直し方のあとにこの直し方を通して読める
- 書き出し・読み込み
  - 作品の中身をそのまま入れているので、書き出しの変更はない
  - 読み込みの中身の確かめ:バージョン7のファイルはパーツ(1つ以上・ID・数)を、6以前は今までどおり作品の数を確かめる
  - 今の古いアプリ(バージョン6)でバージョン7のファイルを読むと、今までどおり「新しい版のアプリで書き出したファイルです」と出る
- テスト:6→7 の直し方(数・履歴・模様・編んだ時間が1つ目のパーツに移る、`tool`、体の色の置き換え)/バージョン1・3・6のファイルが7になって読める/パーツの進み具合の計算/次のパーツへ/複製(名前の左右の置き換え・数が0から)/まとまりごとの並び替え

## 今までの動きを変えないために
- **触らないファイル**:`noZoom.ts`(拡大しない)、`tapGuard.ts`(すばやいタップ・誤タッチ防止)、`voice.ts`・`voiceParse.ts`・`voiceWords.ts`(音声)、`counter.ts`・`pattern.ts`・`knitTime.ts` の今の関数(パーツの数に対してそのまま使う。全体の進み具合の関数は別に足す)、`partnerSvg.ts`・`wearSvg.ts`・`sceneSvg.ts`(絵の下ごしらえ)、`pinch.ts`(2本指の計算)、`useDragSort.ts`・`reorder.ts`(そのまま使う)、`wardrobe.ts`・`lifecycle.ts`、`backup.ts` の書き出しの部分。`tuning.ts` は値を足すだけ
- 編む画面のタップ場所(TapZone)・音声ボタンの中身は変えない。数える先が「作品」から「今のパーツ」に変わるだけ
